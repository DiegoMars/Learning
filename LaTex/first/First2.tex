\section{First example}

The well-known Pythagorean theorem $x^2 + y^2 = z^2$ was proven to be invalid
for other exponents, meaning the next equation has no integer solutions for 
$ n > 2$:
$$
    x^n + y^n = z^n
$$

\section{Second example}

This is a simple math expression $\sqrt{x^2 + 1}$ inside text. And this is also
the same:
\begin{math}
    \sqrt{x^2 + 1}
\end{math}
but by using another command.

This is a simple math expression without numbering
\[\sqrt{x^2 + 1}\]
seperated from text.

This is also the same:
\begin{displaymath}
    \sqrt{x^2 + 1}
\end{displaymath}

\ldots and this:
\begin{equation*}
    \sqrt{x^2 + 1}
\end{equation*}
